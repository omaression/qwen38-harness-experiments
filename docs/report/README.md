# The project report

This directory holds the text of the class deliverable, an IEEE-format project report on the harness and its experiments, one file per section. `docs/paper/main.tex` holds the same text as an IEEEtran conference paper, with `docs/paper/refs.bib`, generated figures in `docs/paper/figures/`, and generated tables in `docs/paper/tables/`.

The text is written formally and in the third person. Every claim in it is meant to be traceable to a file, a committed gate report or a verified reference. The index below gives, for each section, the files to check a claim against.

## Generated tables and figures

Every experiment table in Section V (except the synthetic demo table and ablation synthesis) is generated by

```bash
python scripts/make_report_tables.py          # rewrite the tables after any report changes
python scripts/make_report_tables.py --check  # what tests/test_report_tables.py runs
```

The script reads every `experiments/*/expected/*.json` (40 gate reports total across `exp-a`, `exp-b`, `exp-c`, `exp-c-demo`, and `exp-d`) and writes `docs/report/tables.md`, `docs/paper/tables/<id>-gate.tex` and `<id>-arms.tex`, and the `<!-- BEGIN GENERATED: <name> -->` blocks in `06-results.md`. Similarly, `scripts/make_paper_figures.py` deterministically builds all three vector PDFs under `docs/paper/figures/`, verified by `tests/test_paper_sync.py`. Never edit generated tables or figures by hand.

## Building the paper

```bash
cd docs/paper
TEXMFVAR=/tmp/texmf-var TEXMFCONFIG=/tmp/texmf-config pdflatex -interaction=nonstopmode main.tex
TEXMFVAR=/tmp/texmf-var TEXMFCONFIG=/tmp/texmf-config bibtex main
TEXMFVAR=/tmp/texmf-var TEXMFCONFIG=/tmp/texmf-config pdflatex -interaction=nonstopmode main.tex
TEXMFVAR=/tmp/texmf-var TEXMFCONFIG=/tmp/texmf-config pdflatex -interaction=nonstopmode main.tex
```

`IEEEtran.cls` and `IEEEtran.bst` are checked into `docs/paper/` so compilation works cleanly with standard `pdflatex` and `bibtex`. `docs/paper/main.tex` mirrors sections `01-abstract.md` through `08-conclusion.md`.

## Conventions

- Cite only entries of [09-references.md](09-references.md), checked against published identifiers and kept in citation order with `docs/paper/refs.bib`.
- Every metric in the prose comes directly from a generated table, a committed expected JSON report, or `metrics.compare` / `metrics.both_valid_compare` on the committed cassettes.
- Pre-specified `noninferior/1` gate verdicts are strictly separated from post-hoc diagnostics (`both_valid_compare`, per-item breakdown, and exploratory margin sensitivity).
