# Abstract

Large language model (LLM) features regress silently whenever prompts, adapters, quantization, or serving stacks change. We present a deterministic continuous-integration (CI) regression harness (`llm-eval`) spanning four features (`bugfix`, `judge`, `review`, `patch`). Replies are recorded once as SHA-256 request-addressed cassettes and replayed offline with execution-grounded value sandboxing, AST/regex static analysis (SAST), paired cluster-bootstrap intervals, exact McNemar testing, non-inferiority gating, and a hash-chained promotion ledger. On small or near-ceiling suites (`demo` $n=13\text{--}42$, HumanEvalFix $n=74$ at 0.986), bf16 rerun noise ($\pm 0.041$) masks modest capability shifts—rejecting an identity LoRA on single-reply serving variation and placing ternary Bonsai-2-27B's $-$0.027 loss inside the noise band at $1.60\times$ tokens—while catching format collapse (0.846 < 0.95). Non-ceiling real-repository Qwen3.8-27B evaluations restore discriminative power. On SWE-Review-Bench ($n=400$), a thinking-calibrated LoRA improves balanced accuracy by $+0.188$ ($0.533 \to 0.720$, $p=2.26\times 10^{-13}$), retaining $+0.089$ ($p=6.17\times 10^{-4}$) on mutually valid replies. On 297 multi-file patch tasks, changing coder effort from `xhigh` to `medium` raises held-out usable patch rate by $+0.391$ ($0.479 \to 0.870$, $p=5.25\times 10^{-16}$) at $5.02\times$ fewer pooled tokens ($5.26\times$ held-out). Complementary ablations expose a $-0.040$ security regression ($p=0.023$) hidden by a $+0.048$ uncapped format gain, and show deterministic `tests+SAST` gating eliminates 34.8% auditor false rejects while cutting tokens per resolved task $7.0\times$.

**Index Terms**—large language models, evaluation, regression testing, continuous integration, statistical hypothesis testing, low-rank adaptation, quantization.
